I'm a **Full Stack Developer** focused on building maintainable, scalable and production-ready software.

Programming started as a curiosity when I was 15 and eventually became my profession. Since then, I've worked across **backend, frontend and distributed systems**, combining software engineering with an increasing focus on **AI, GenAI and system architecture**.
